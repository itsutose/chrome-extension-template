# 【新機能】メモ表示UI（Google Keepライク）の実装

## 概要
002-Aで実装した復元アルゴリズムを使用して、選択したテキストの位置にGoogle KeepライクなメモUIを表示する機能を実装する。メモは新規HTML要素として作成され、選択テキストの最下部に配置される。

## 背景と課題
- テキスト選択・右クリックメニュー機能は実装済み（001）
- メモ復元位置特定アルゴリズムは実装済み（002-A）
- メモを表示するUIコンポーネントが未実装
- メモの表示・非表示切り替え機能が未実装
- 選択テキストへの編みかけ（表示/非表示切り替え用）が未実装
- 復元アルゴリズムとUIの連携が未実装

## 期待する結果
- 002-Aの復元アルゴリズムを使用して正確な位置にメモの矩形要素が表示される
- メモはGoogle Keepライクなデザインで表示される
- 選択したテキストに編みかけが表示され、クリックでメモの表示/非表示を切り替えられる
- メモの矩形要素はページの既存スタイルを汚染しない
- メモの位置はページのスクロールやリサイズに適切に対応する
- 復元アルゴリズムとの連携が正常に動作する

## 実装方針
- **React Component**: メモ表示用のReactコンポーネントを作成
- **Portal**: ReactDOM.createPortalを使用してページの既存スタイルを汚染しない
- **Algorithm Integration**: 002-Aの復元アルゴリズムとの連携
- **CSS**: CSS変数を使用したテーマ管理とレスポンシブデザイン
- **編みかけ**: 選択テキストに小さなインジケーターを追加
- **分離設計**: メモ作成と位置指定を分離し、再利用性を向上
- **位置固定**: スクロール時に画面にスティックしない固定位置表示

## 影響範囲
- `src/utils/memo.tsx`: メモ表示コンポーネントとユーティリティ関数の実装
- `src/styles/memo.css`: メモ用のスタイル定義（外部CSS分離）
- `src/types/memo.ts`: メモ表示に関する型定義の追加・分離設計対応
- `src/content.tsx`: メモ表示ロジックと復元アルゴリズムの統合・分離設計対応

# 【新機能】メモ表示UI（Google Keepライク）の実装

## 概要
選択したテキストの位置にGoogle KeepライクなメモUIを表示する機能を実装する。メモは新規HTML要素として作成され、選択テキストの最下部に配置される。

## 背景と課題
- テキスト選択・右クリックメニュー機能は実装済み（001）
- メモを表示するUIコンポーネントが未実装
- メモの位置決めロジックが未実装
- メモの表示・非表示切り替え機能が未実装
- 選択テキストへの編みかけ（表示/非表示切り替え用）が未実装

## 期待する結果
- 選択したテキストの最下部（y座標最大位置）にメモの矩形要素が表示される
- メモはGoogle Keepライクなデザインで表示される
- 選択したテキストに編みかけが表示され、クリックでメモの表示/非表示を切り替えられる
- メモの矩形要素はページの既存スタイルを汚染しない
- メモの位置はページのスクロールやリサイズに適切に対応する

## 実装方針
- **React Component**: メモ表示用のReactコンポーネントを作成
- **Portal**: ReactDOM.createPortalを使用してページの既存スタイルを汚染しない
- **Positioning**: 選択テキストの位置情報を基にメモの配置を計算
- **CSS**: CSS変数を使用したテーマ管理とレスポンシブデザイン
- **編みかけ**: 選択テキストに小さなインジケーターを追加

## 影響範囲
- `src/components/MemoDisplay.tsx`: メモ表示コンポーネントの新規作成
- `src/components/MemoIndicator.tsx`: 編みかけコンポーネントの新規作成
- `src/content.tsx`: メモ表示ロジックの統合
- `src/styles/memo.css`: メモ用のスタイル定義
- `src/types/memo.ts`: メモ表示に関する型定義の追加

# Issue 010: ディレクトリ構造の再編成と最適化

## 概要
プロジェクトの成長に伴い、現在のディレクトリ構造が複雑化・分散化している問題を解決するため、機能別・用途別の明確なディレクトリ構造に再編成を行う。

## 背景
### 現在の問題点
1. **機能の分散**: 関連する機能が様々なディレクトリに散らばっている
2. **本番/開発コードの混在**: テスト用コードと本番用コードが同一ディレクトリに存在
3. **スケーラビリティの欠如**: 新機能追加時の配置基準が不明確
4. **保守性の低下**: ファイルの目的と責任範囲が不明確

### 前段階での成果（feature-009）
- content.tsxの本番/開発分離完了
- 4つのテストファイルの統合完了
- 環境変数による条件分岐実装済み

## 期待される結果
### 1. 明確な責任分離
- 本番用コア機能の分離
- 開発・テスト機能の独立
- 機能別モジュールの明確化

### 2. 保守性の向上
- ファイルの目的が一目で判別可能
- 新機能追加時の配置基準明確化
- 依存関係の整理と最適化

### 3. ビルド最適化
- 本番ビルドでの開発用コード除外
- バンドルサイズの最適化
- 機能別の分割ビルド対応

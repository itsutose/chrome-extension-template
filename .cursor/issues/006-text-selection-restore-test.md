# 【テスト実装】テキスト選択・メモ復元位置特定のテスト環境構築

## 概要
テキスト選択アルゴリズムとメモ復元位置特定の精度を検証するためのテスト環境を構築する。選択して取得した位置情報をもとに、同じ位置に正確に復元できるかをコンソールとデータ照合で検証し、PDCAサイクルを効率的に回す基盤を提供する。

## 背景と課題
- 001番のissueでテキスト選択機能は実装済み
- メモ復元位置の特定アルゴリズムの精度検証が必要
- 現在はログ出力のみで、位置情報の正確性を検証できない
- 異なるWebサイトでの動作確認が手動で時間がかかる
- 位置情報の精度と復元成功率の定量評価ができない
- メモ作成機能は現時点では不要（002番のissueで実装予定）

## 期待する結果
- テキスト選択時に位置情報が正確に取得されることをコンソールで確認できる
- 取得した位置情報をもとに同じ位置に正確に復元できることを検証できる
- 異なるWebサイトでの位置特定精度を比較できる
- 復元成功率の統計情報がコンソールに表示される
- テストデータの保存・読み込みが可能（将来的な拡張のため）

## 実装方針
- **位置情報検証**: 選択位置の取得と復元位置の照合
- **コンソール出力**: 詳細なデバッグ情報と検証結果の表示
- **データ照合**: 取得位置と復元位置の一致度検証
- **統計情報**: 精度と成功率の数値化
- **将来拡張**: 可視化機能の基盤準備（現時点では実装しない）
